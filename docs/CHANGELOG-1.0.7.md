# TVDesk 1.0.7

版本：1.0.7（versionCode 8）
日期：2026-11-01

1.0.6 发布后用户报的三个问题，逐个修掉。

---

## 1. 装完就静默接管 HOME（不用再去无障碍里点）

**现象**：装好之后按 HOME 还是回电视自带的桌面。

**根因**：`HomeGuardService` 是无障碍服务，系统要求用户去「设置 → 无障碍」里手动打开，
电视上这条路又长又难找，实际没人会去。Aerial 是装的时候用一条 adb 命令把服务写进
`enabled_accessibility_services`，用户全程不动手。

**改法**：新增 `GuardSetup`。

- 应用拿到 `WRITE_SECURE_SETTINGS`（adb 授权过一次就有）时，启动时自己把守护写进系统设置；
- 没这个权限（U 盘装、应用商店装）就**什么都不做**，不弹窗不引导，设置页里留出口；
- **升级后自动重绑**：无障碍配置（比如这一版加的 HOME 键过滤）只在服务绑定时读一次，
  升级 APK 不会重读，表现是「守护开着但按 HOME 不拦」。版本号一变就把服务摘掉再挂回去，
  逼系统重读配置。

设置页里的「桌面守护」也改成：有权限就直接开，没权限才跳到系统无障碍页。

**实测**（MiTV-MFTR0）：adb 授权后启动应用，`settings get secure enabled_accessibility_services`
立刻变成 `com.tvdesk.app/com.tvdesk.desk.HomeGuardService`；在别的应用里按 HOME 回到 TVDesk。

> 补一句这台机器的限制：它的 `A11yInputFilter Info` 一直是空的，也就是系统不装按键过滤器，
> 所以 `onKeyEvent` 拿不到 HOME（看不到「onKeyEvent HOME」日志）。实际接管走的是
> 「原桌面窗口出现 → 拉回」这条路，能回，但会闪一下原桌面。这个由固件决定，
> 代码里两条路都留着，能拦的机器就拦。

## 2. 音乐 / B 站下滑时卡片印到标题和顶栏上

**现象**：在音乐页或 B 站页向下翻，卡片会画到顶栏、标题、「播放全部」上面，糊成一片。

**根因**：墙为了不裁掉「聚焦放大」的边，设了 `clipChildren = false`；而这两页的标题和页签
是浮在墙上面的（不在布局里占位置）。于是墙一滚，滚出去的卡片照样被画出来，正好压在标题上。

**改法**：`TileWall.dispatchDraw` 里显式裁一刀到自己的视口。注意裁剪矩形要带上 `scrollY` ——
`dispatchDraw` 的 canvas 已经按滚动量平移过了，写 `(0,0,w,h)` 裁的是「内容里的左上角」，
等于没裁（第一版就是这么错的）。

各页给墙留 `paddingTop = 18dp`，专门放聚焦放大溢出的那一圈，所以裁完框还是完整的。

**实测**：音乐页连续下翻，标题「每日推荐」和「播放全部」始终干净；B 站同样。

## 3. 设置页重做，和其它模块一个样子

**现象**：设置页还是「两列设置行 + 面包屑」，和音乐/B 站/应用完全两个风格，
从桌面点进来像换了个 App。

**改法**：整页重写。

- 结构照其它模块：左上胶囊（点了回桌面）+ 一排页签 + 卡片墙；
- 页签分三组：**桌面**（内容源 / 桌面守护 / 设为默认桌面 / 电视系统设置）、
  **播放**（切走继续播放 / 显示时钟 / 显示天气）、**关于**（检查更新 / 更新源 / 版本）；
- 每张卡三行：是什么 / 现在什么状态 / 按下去会发生什么（电视上离得远，一行小字看不清状态）；
- 焦点、放大、白环、到边回弹全部复用 `TileWall`，和其它模块手感一致。

顺带把「更新源」从纯文本框变成一张卡（留空即用内置镜像），「检查更新」的弹窗换成
带「忽略此版本」的那套。
