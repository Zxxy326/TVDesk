# TVDesk 1.1.0

版本：1.1.0（versionCode 11）
日期：2026-11-01

主题：**消灭「焦点被裁掉一角」** —— 全桌面统一的过扫安全边距、卡片墙焦点留白、动画参数归一。

## 1. 顶栏不再被屏幕边缘裁掉

真机上是 5% 过扫描（overscan）：1280dp 画布左右各被吃掉约 42dp、顶底各 36dp。
以前顶栏离屏顶只有 20dp、离左只有 25dp，胶囊和页签的聚焦放大正好画进过扫区，
表现就是「顶栏各个模块被裁切」。

- `top_bar_top` 20 → 40dp，`screen_pad` 25 → 48dp（按 5% 过扫 + 余量取值）；
- 各模块内容起点统一成 `content_top = 100dp`（顶栏下缘 + 16）；
- 顶栏类目预算公式修正：右侧只按过扫安全距离让位（顶栏是居中悬浮的），
  之前两侧都按切换器宽度让，边距加大后类目被整排折进「更多」。

## 2. 卡片墙统一「焦点留白」，第一行/边缘的焦点框不再缺角

墙为了挡住「滚出视口的卡片压标题」，按自己的视口裁剪；但应用页、B 站、信号源的墙
顶部没有留白，第一行聚焦放大 1.15 时上沿正好被裁掉。

- 新增 `wall_room_top/bottom = 24dp`、`wall_room_side = 14dp`，所有墙（应用 / B 站 / 音乐 /
  搜索 / 信号源 / 设置 / 桌面海报墙 / 收藏双栏）统一从这取；
- 配对负 margin 抵消，视觉位置不变；
- 到边回弹（nudge）的 9dp 位移现在会把裁剪跟着放宽，回弹不再被裁剪吃掉。

## 3. 收藏模块焦点加固

实测基本链路（UP 回页签 / DOWN 进墙 / OK 打开）是通的；报的「失效」主要发生在
**长按删条目之后**：清单重建把子视图整批 detach，焦点掉到窗口第一个可聚焦控件。

- 长按取消收藏 / 删除历史后，焦点自动送回这一栏的第一张；
- 空态提示在不可重试（本地清单为空）时不可聚焦，不再成为焦点黑洞。

## 4. 设置页与其它模块对齐

- 顶栏重排：胶囊 top|start + 页签 top|center（原来两颗挤在一起靠左）；
- 操作逻辑统一：页签左右到边吃掉、第一排按上回页签、点页签焦点进内容。

## 5. 动画参数归一

聚焦放大统一 `FocusScaler.SCALE_FOCUSED = 1.06`：收藏海报墙 1.08、搜索结果 1.08、
设置卡 1.05、Hero 按钮 1.10 全部收拢（应用页磁贴保留 Aerial 的 1.15）。

## 验证（MiTV-MFTR0 实机）

- 首页顶栏离屏顶/左约 40/48dp，页签完整；类目一排全在（首页/收藏/玩偶电影/玩偶剧集/动漫/综艺/臻彩视界/短剧/音乐/搜索）
- 应用页：第一行磁贴 1.15 放大 + 白环完整
- 设置页：顶栏胶囊左上、页签居中；第二行卡片白框完整
- 搜索页：结果墙正常
