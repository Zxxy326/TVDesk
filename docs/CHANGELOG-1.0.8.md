# TVDesk 1.0.8

版本：1.0.8（versionCode 9）
日期：2026-11-01

这一版只有一个主题：**把更新检查的 CDN 缓存问题修掉**。功能与 1.0.7 完全一致。

## 问题

1.0.7 发出去之后，用 1.0.6 的电视查更新，拿到的还是 1.0.6 的清单，于是「已是最新」。

根因是更新清单放在 jsDelivr 的 `@main` 分支路径上：
- jsDelivr 对分支路径的缓存最长 **12 小时**；
- 我们发版时调用过 purge，但边缘节点没有全部失效，仍然有节点在发旧文件；
- 客户端又是「第一个成功的源就用」，拿到旧清单就停了，不会去问别的源。

## 改法

1. 首选源换成 `@latest`（解析到最新 tag）。tag 是不可变的，缓存不会把上一版的文件当这一版返回；
2. 所有源都问一遍，**取 versionCode 最大的那个**，而不是第一个成功的 —— 某个镜像滞后也不会让客户端误判「已是最新」；
3. `@main` 降到最后一位，只当兜底。

## 对已经装着的版本意味着什么

- 1.0.7 的客户端仍然会先问 `@main`（缓存里是 1.0.6），所以**最多 12 小时后**才会看到这一版；
- 想立刻升：直接覆盖安装 1.0.8，或者等这一波缓存过期；
- 从 1.0.8 起，后续发版不再需要手动 purge CDN，客户端第一时间就能拿到。

## 其它

功能、界面、签名与 1.0.7 完全一致：

- 装完自动接管 HOME（`GuardSetup`）
- 音乐 / B 站下滑不再把卡片画到标题上
- 设置页：胶囊 + 页签 + 卡片墙
