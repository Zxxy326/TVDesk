# TVDesk 1.0.6 开发日志：按 Aerial 的架构重做焦点与桌面接管

版本：1.0.6（versionCode 7）
日期：2026-11-01

参考：aerial-tv `docs/ARCHITECTURE.md`。**不含**它的屏保、按键音、壁纸、背景（用不到）。

---

## 0. 为什么推倒重来

原来的焦点是「系统几何寻焦 + 逐页拦截补丁」：10 个文件里 25 处 `dispatchKeyEvent`、
121 处 `requestFocus`，边界靠 `atHorizontalEdge` / `swallowAtEdge` / `markUserLeft` 这类补丁压着。
每加一个页面、一个浮层，就得把同一套补丁再打一遍 —— 所以它永远修不完。

Aerial 那边焦点是**数据**：每格一个按 key 存的 `FocusRequester`，行尾是
`FocusRequester.Cancel`，浮层一开底层 `focusable = false`，磁贴**根本不回收**（绝对位置摆放）。

差距就在这：一边是「我要去哪一格」，一边是「系统你猜我要去哪，猜错了我再拦一下」。

## 1. 新增的三个类

| 文件 | 作用 |
| --- | --- |
| `motion/SpringValue.java` | 临界阻尼弹簧（`dampingRatio = 1`，半隐式欧拉）。改目标就行，连按不排队 |
| `motion/FocusNav.java` | 显式二维焦点路由：左右 ±1、上下 ±列数、到边交页面或回弹、按 key 记忆 |
| `widget/TileWall.java` | 不回收的磁贴墙：全量挂载 + 弹簧滚动 + 翻页 + 边缘回弹 + 滚动回调 |

`TileWall` 同时替掉了 `GridView` 的三个老毛病：

- **子视图回收** → 带焦点的那张被回收，焦点没主，系统按「窗口里第一个可聚焦控件」补
  —— 正好是左上角胶囊，用户看到「翻页跳一下左上角」。全量挂载后这个问题从根上消失；
- **下一排还没挂载** → 几何寻焦找不到目标，焦点被甩给别处。现在位置是算出来的；
- **整行对齐** → 滚动目标改成 `row × 行距`（Aerial 的 `scrollFor`），每次换行都是完整一排在动。

## 2. 迁到新内核的页面

| 页面 | 列数 | 说明 |
| --- | --- | --- |
| 应用（`AppPage`） | 5 | 保住长按移动 / 自定义排序，焦点按包名找回 |
| 哔哩哔哩（`BiliPage`） | 6 | 保住滚到底加载更多（`TileWall.ScrollListener`） |
| 音乐（`MusicPage`） | 6 | 第一排上→播放全部/页签，最后一排下→播放条 |
| 搜索（`SearchPage`） | 4 | 左到边回字母键盘，上到顶回输入框 |
| 信号源（`SignalPage`） | 6 | 第一排上→页签 |
| 桌面海报墙（`CategoryWall`） | 6（收藏双栏 3） | 第一排上→顶栏页签；收藏左右双栏可跨栏 |
| 首页海报行（`DeskActivity`） | — | 左右到边回弹（一次 8dp 位移） |

每页顺手删掉的东西：`focusGrid` 的 32ms 重试链、`markUserLeft/markUserEntered`、
`atHorizontalEdge` 的逐键判断、`addOnLayoutChangeListener` 里的抢焦。

**选集格**（详情页 32 格）没动：它一屏铺满、不滚动，本来就没有回收导致的丢焦问题。

## 3. 磁贴动画

`AppTileView` 自己驱动两根弹簧：

- 放大 1.15 倍走 `STIFF_FOCUS`（临界阻尼，不过冲 —— 回过冲白框会抖）；
- 白环单独一根、刚度更高：**从磁贴边缘长出来**（间隙 0 → 5dp），消失比缩小更快，
  左右移动的路上不会同时看到两个框；
- 复用视图时 `syncFocusState()` 对齐一次（以前搬动卡片后第一张会偏大、名字被下一行的磁贴盖住）。

## 4. 桌面接管（`guard`）

| 能力 | 以前 | 现在 |
| --- | --- | --- |
| HOME 键 | 只靠「原桌面窗口出现后拉回」，原桌面会先闪一下 | `onKeyEvent` 在**按下那一刻**吞掉 HOME 并把自己叫到前台 |
| 开机/亮屏 | 只有开机广播 | 亮屏后等 1.5s 再看一眼前台，仍是原桌面才拉回 |
| 主动进原桌面 | 会被立刻拉回（用不了） | 应用页点开固件桌面时记 1 小时放行期；回 TVDesk 立刻作废 |
| 前台判断 | 只看窗口包名 | 记录最近前台包名，浮层/对话框不算 |

配置侧：`accessibility_home.xml` 打开 `flagRequestFilterKeyEvents` + `canRequestFilterKeyEvents`。

## 7. 在线更新（本轮新增）

| 环节 | 做法 |
| --- | --- |
| 什么时候查 | 回到桌面时顺手查一次，**12 小时最多一次**；查不到、没新版都静默 |
| 查哪里 | 三个内置源依次试：jsDelivr CDN → gitmirror → GitHub raw（前两个国内可直连） |
| 清单 | 仓库里的 `dist/update.json`：`versionCode` + 说明 + 按 ABI 分的三个包地址 |
| 挑哪个包 | 按 `Build.SUPPORTED_ABIS` 选：32 位电视下 24MB 的 v7a，不去下 38MB 通用包 |
| 弹窗 | 「下载并安装 / 忽略此版本 / 以后再说」；忽略记的是 versionCode，同版本不再骚扰 |
| 下载 | 依次套镜像前缀（ghfast / gh-proxy / ghproxy / moeyy / 直连），显示百分比进度 |
| 校验 | 落地的文件必须是 zip（apk 头 `PK\3\4`）—— 加速站有时返回 200 加一张错误页 |

设置页里的「更新源」留空即走内置源；填了自定义地址仍然优先用填的那个（自建源照旧可用）。
